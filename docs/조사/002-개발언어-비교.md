# Discord 연동 언어와 AI Companion 적합성

- 조사일: 2026-09-13
- 관련 프로젝트: [ai-companion](../프로젝트.md)
- 검증 상태: 자료 조사. 언어별 구현·성능 비교는 수행하지 않았다.

이 문서는 언어 선택 전의 비교 기록이다. 이후 사용자 요청으로 Python·discord.py와 LM Studio를 선택했다. 현재 채택 내용은 [결정 기록](../결정/001-Python-LMStudio-초기연결.md)을 따른다.

## 핵심 요약

이 프로젝트에는 Python을 우선 추천했다. Discord 연동 자체가 Python만의 장점은 아니다. 로컬 LLM과 외부 API를 호출하는 기능은 여러 언어로 구현할 수 있다. 이후 임베딩·기억 추출·로컬 추론·모델 평가를 직접 실험할 가능성과 작은 MVP의 개발 흐름을 고려하면 Python이 잘 맞는다는 판단이다. Go는 사용자 요청으로 선택 후보에서 제외했다.

아래 장단점은 각 라이브러리의 지원 내용과 언어 특성을 프로젝트 요구에 적용한 설계 판단이다. 성능 순위나 라이브러리 인기도 순위가 아니다.

## 모델을 사용한다는 이유만으로 Python이 필요한가

두 작업을 구분한다.

1. **추론 서버 호출**: Ollama나 외부 API에 HTTP 요청을 보낸다. Ollama는 HTTP API와 Python·JavaScript 라이브러리를 안내한다. 서버가 추론을 담당하므로 봇 언어를 Python으로 바꾼다고 모델 자체의 속도가 빨라지는 것은 아니다. [Ollama API 소개](https://docs.ollama.com/api/introduction)
2. **모델·임베딩을 직접 실행하고 실험**: Transformers의 Python 모델 로딩·추론 기능 같은 생태계를 직접 쓸 수 있다는 점이 Python의 장점이다. 다만 봇과 무거운 추론을 반드시 같은 프로세스에 넣어야 한다는 뜻은 아니다. [Transformers](https://huggingface.co/docs/transformers/en/index)

따라서 API 호출과 풍부한 웹 UI가 대부분이면 TypeScript도 좋은 후보이다. 이 프로젝트처럼 기억 구조·추출·모델 비교를 차례로 연구하고 싶다면 Python을 기본으로 시작할 이유가 더 크다.

## 객체지향 목표에 적용

Python에서도 `ChatModel`, `MessageSink`, 저장소 포트를 통해 교체 가능한 구조를 작성할 수 있다. `Protocol`은 구조적 인터페이스를 표현하고, 타입 검사기는 사용처의 계약을 검사한다. [Python Protocol](https://docs.python.org/3/library/typing.html#typing.Protocol)

권장 조합은 Python + discord.py + FastAPI이며, 모델은 Ollama 어댑터와 외부 API 어댑터로 나눈다. 구현 시 타입 검사기를 실행 절차에 포함하고, 입력 스키마 검증과 어댑터 계약 테스트를 둔다. 나중에 관리 화면이 복잡해지면 프런트엔드만 TypeScript로 분리할 수 있다. 이러한 분리는 현재 MVP의 필수 작업이 아니다.

## 개발 난이도에 대한 판단

기존 숙련도가 비슷하고 현재의 작은 관리 화면·Discord 봇·AI 실험 범위를 기준으로 하면 Python을 가장 수월한 후보로 본다. TypeScript는 웹 화면까지 같은 언어로 다룰 때 이점이 있고, C#과 Java/Kotlin은 타입·인터페이스의 도움을 받는 대신 익숙하지 않은 실행·빌드 환경의 초기 학습이 필요하다. 이는 실측 순위가 아니며 기존 경험과 선택한 프레임워크에 따라 달라진다.

Python에서는 초기에 작성할 코드가 간결해도 규모가 커질 때 수정 실수를 줄이려면 타입 힌트·정적 검사·작은 포트 계약을 유지해야 한다. 복잡한 웹 UI가 중심으로 바뀌면 TypeScript의 개발 난이도를 다시 평가한다. 가장 빨리 첫 버전을 만드는 난이도와 장기 유지보수의 난이도를 구분한다.

## 남은 판단

기존에 가장 익숙한 언어가 무엇인지, 로컬 추론을 직접 다룰 정도와 관리 화면 규모가 어느 정도인지가 최종 선택에 영향을 준다. 현재 추천은 Python이며, Discord 지원의 유무만으로 선택한 것은 아니다.
