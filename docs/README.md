# 프로젝트 문서 안내

채택한 구현 방향은 로컬 서버 + 로컬 웹 UI다. 현재 실행 가능한 CLI와 새 방 백엔드 기반은 [프로젝트 README](../README.md)에서 구분해 안내하며, 웹 UI 실행 명령은 아직 제공하지 않는다. 구현을 시작할 때는 아래 순서로 필요한 문서만 읽는다. 상태·일정은 프로젝트 문서, 채택된 기술은 결정 기록, 각 설계의 상세 내용은 해당 원본에서 관리한다.

## 먼저 읽기

1. [프로젝트의 구현 순서와 작업 목록](프로젝트.md#구현-순서): 어디부터 만들고 무엇을 검증할지.
2. [기초 설계](기초설계.md): 독립된 방·원본 사본·편집·삭제·재시작 계약.
3. [UI 설계](UI설계.md): 홈·채팅·좌우 설정 화면과 실시간 입력 요구.
4. [저장 배치 결정](결정/003-내부연결DB-외부방별SQLite.md)과 [현재 데이터 설계](데이터설계.md): 내부/외부 저장 원본, DB 안의 FK와 저장소 간 논리 참조, 복구·삭제 계약.
